ROOMEQ EST MAINTENANT AUTONOME (2.0.0)
--------------------------------------
Plus AUCUNE application tierce (câble audio virtuel, console externe) :
  • Carte son virtuelle INTÉGRÉE « RoomEq Virtual Audio » (pilote roomeqvad)
    — paire « RoomEq Input / RoomEq Output » installée en un clic depuis
    l'onglet Mixage, ou automatiquement par l'installateur MSI. Le paquet
    pilote est livré avec l'application : RIEN n'est téléchargé.
  • Pilote ASIO INTÉGRÉ « RoomEq ASIO » : votre DAW (REAPER, Cubase, FL
    Studio, Ableton…) choisit « RoomEq ASIO » comme sortie, sa lecture
    alimente la piste « DAW (ASIO) » du mixeur, traverse l'égaliseur, puis
    sort sur la vraie carte son (48 kHz stéréo).
  • INSTALLATEUR MSI complet (application + pilote + ASIO) : RoomEq-2.0.0-
    win-x64.msi — Programs and Features, désinstallation propre.
  • Distribution « exécutables » sans MSI : application PORTABLE (un seul
    fichier), application INSTALLABLE (RoomEqAppSetup : raccourcis +
    lancement automatique au démarrage de Windows, sans UAC) et setup
    pilote/ASIO (RoomEqDriverSetup) — voir INSTALLATION-PILOTE.md.
  • Boucle WASAPI conservée comme solution sans pilote (aucune installation).

INSTALLATION
------------
EXECUTABLES (recommande si Windows bloque le MSI) :
    1) RoomEqDriverSetup-2.2.2.exe : la carte son + l'ASIO en un fichier
       (pilote embarque). Double-clic -> UAC -> FENETRE GRAPHIQUE (v2.2.0) :
       panneau d'etat + journal + boutons Installer / Diagnostic complet /
       Revenir au mode normal / Desinstaller. Le mode test est PROPOSE
       en boite de dialogue (jamais active en silence, defaut : NON).
       Options console (support) : --status (etat + VERDICT si la carte
       manque) / --uninstall / --mode-normal / --accept-testmode /
       --no-testmode.
    2) RoomEq-2.2.2-win-x64.exe : l'application PORTABLE en un seul fichier
       (~45 Mo) — aucune installation, aucun UAC.
    3) RoomEqAppSetup-2.2.2.exe : la meme application en version INSTALLABLE
       (l'exe portable ET le setup pilote sont embarques dedans) —
       installation sans UAC dans
       %LOCALAPPDATA%\Programs\RoomEq, raccourcis Menu Demarrer/Bureau,
       LANCEMENT AUTOMATIQUE AU DEMARRAGE DE WINDOWS (propose, desactivable),
       entree « Applications & fonctionnalites » avec desinstalleur.
       Options : --status / --uninstall / --no-autostart / --no-desktop.
       Reglages et mesures (%APPDATA%\RoomEq) partages avec la version
       portable et conserves a la desinstallation.
MSI (voie historique) : double-clic, acceptez l'invite administrateur — TOUT est
    automatique : certificat de test, mode test Windows (redémarrage proposé
    si nécessaire), pilote, périphérique « RoomEq Virtual Audio » et ASIO.
Zip portable     : décompressez puis lancez RoomEq.exe (pilote installable
    depuis l'onglet Mixage, voir INSTALLATION-PILOTE.md).

SIGNATURE DU PILOTE (à lire une fois)
-------------------------------------
Windows n'accepte que les pilotes signés. Tant que le projet n'a pas de
certificat EV, le pilote est SIGNÉ-TEST : le MSI active automatiquement le
mode test et importe le certificat — après l'unique redémarrage proposé,
les périphériques « RoomEq Input / RoomEq Output » apparaissent (filigrane
« Mode de test » en bas à droite : normal). Si le Secure Boot est actif,
voyez INSTALLATION-PILOTE.md.
L'application fonctionne sans pilote via la boucle WASAPI.
La voie officielle (attestation Microsoft, certificat EV) y est aussi décrite.

VERSIONS TEST / PUBLIC — LE SILENCE PAR DÉFAUT (2.0.0)
------------------------------------------------------
Le même binaire se comporte selon son NOM :
  • RoomEq.exe (public, par défaut) : AUCUN journal écrit, AUCUN envoi.
  • RoomEq-test.exe (test) : journalisation complète + télémétrie Drive

Le mode test peut aussi être forcé par la variable d'environnement
ROOMEQ_TEST=1 (développement). Le zip PUBLIC contient RoomEq.exe seul ; le
zip TEST contient les deux exécutables + telemetrie.json + le dossier
driver\ du pilote.

MIXAGE & ROUTAGE (rappel)
-------------------------
  • Onglet Mixage : « Installer le pilote RoomEq… » installe la carte
    virtuelle (paquet local), « Router Windows vers l'EQ » démarre la chaîne
    Windows → RoomEq Input → RoomEq Output → EQ → carte physique.
  • Les périphériques par défaut d'origine sont mémorisés et restaurés à
    l'arrêt du routage (même après fermeture de l'application).
  • Chaque piste a son propre EQ + fader/pan/mute/solo/VU ; l'EQ principal
    s'applique au bus master en temps réel.
  • « Supprimer le pilote » désinstalle la carte virtuelle (maintenance).
  • DAW : piste « DAW (ASIO) » + sortie « RoomEq ASIO » dans votre DAW ;
    le statut du pont s'affiche dans la barre du Mixage.

LES DEUX CURSEURS DE VOLUME RESTENT SYNCHRONISÉS (1.9.1, conservé)
-------------------------------------------------------------------
Le curseur « Volume » de la barre du haut et le curseur « Vol. carte
physique » de la tranche MASTER règlent le MÊME volume Windows de la carte
physique : déplacer l'un met l'autre à jour immédiatement, quel que soit
l'ordre ; les réglages faits hors de l'application (mixeur Windows, touches
du casque) sont suivis à l'écran. Ctrl+Alt+↑ / ↓ / M : ±5 % et sourdine.

CALIBRATION (rappel)
--------------------
Micro PHYSIQUE requis (les cartes virtuelles « ne captent pas la pièce ») :
signaux de test joués sur la sortie, mesure croisée multi-signaux (balayage
Farina + bruits), preset de correction automatique (bandes, fréquences, Q
optimisés), import direct dans l'égaliseur avec précision au choix
(douce/standard/fine/très fine). Bibliothèque de 36 profils micro + éditeur
graphique + import .cal/CSV REW.
