RoomEq 3.9.1 — recodage TRIADE + EQ système sans pilote + greffons DAW + installation 1 clic
=====================================================================================================

CE QU'EST CETTE VERSION
-----------------------
  • RECODAGE COMPLET de l'application (RoomEq.Core, RoomEq.Audio, RoomEq.App)
    selon le protocole TRIADE : chaque module est défini par une spécification
    d'intention diffable (I/), implémenté par du code versionné (src/) et
    cartographié à adresse stable (CARTE.md) — 46 modules, 48 spécifications,
    483 tests verts + vérifications natives (AU 15 671 + VST 430/41 + APO 112),
    build 0 erreur 0 avertissement.
  • CORRECTIF 3.9.1 — ACTIVATION DE L'EQ SYSTÈME SUR TOUTES LES SORTIES :
    les sorties dont le pilote ne déclare aucun effet (pilotes génériques
    Windows, ex. « Haut-parleurs (Realtek(R) Audio) ») rejetaient
    l'activation (« n'expose pas de slot d'effets système »). RoomEq crée
    désormais lui-même l'emplacement d'effets manquant — c'est le mécanisme
    éprouvé d'Equalizer APO (10+ ans de terrain) : l'activation réussit sur
    ces sorties, et la désactivation supprime l'emplacement créé s'il est
    redevenu vide (restitution exacte de l'état d'origine). Les tentatives
    antérieures échouées sont reprises proprement au prochain clic.
  • NOUVEAU 3.9.0 — CONSOLE RETIRÉE, VERDICT VISIBLE, INSTANCE UNIQUE (D26) :
    la console de mixage interne (lecteur, générateur, pont DAW ASIO, bus
    master, EQ de piste) disparaît de l'onglet Mixage — depuis l'EQ système
    sans pilote, elle ne faisait que doubler des fonctions déjà couvertes
    (lecteur et signaux de test de la barre du haut, greffons VST/AU pour
    les DAW). L'onglet Mixage devient le poste de pilotage de l'EQ système :
    sorties à activer, VERDICT de chaque action affiché en couleur DANS le
    panneau (un échec d'activation — invite refusée, périphérique retiré —
    ne peut plus passer inaperçu : « le bouton ne s'active pas »
    affiche désormais sa raison), volume de la carte physique d'écoute et
    preset adapté à la sortie. Anti-double-correction étendue au lecteur
    interne : si l'EQ système couvre la sortie de lecture, l'EQ local du
    lecteur se contourne (aucune correction doublée). L'application refuse
    désormais de s'ouvrir plusieurs fois (l'installateur lançait parfois
    plusieurs instances en même temps). Migration automatique conservée :
    sortie d'origine restaurée si la carte virtuelle héritée était encore
    la sortie par défaut ; bouton de suppression du pilote hérité.
  • NOUVEAU 3.7.0 — EQ SYSTÈME SANS PILOTE (D24) : l'onglet Mixage gagne un
    panneau « EQ système (sans pilote) ». Activez l'EQ sur une ou plusieurs
    sorties Windows (enceintes, casque, HDMI…) : TOUT le son de ces sorties
    — musique, navigateur, jeux, notifications — traverse l'égaliseur de
    l'onglet Égaliseur, en temps réel. L'installation se fait DANS le moteur
    audio de Windows (technologie officielle « Audio Processing Object », la
    même que les effets Realtek/Dolby) : AUCUN pilote, AUCUN mode test,
    AUCUN logiciel tiers (VB-CABLE n'est plus nécessaire), et AUCUNE latence
    ajoutée — aucune désynchronisation son/image en vidéo. Activation = une
    invite administrateur (le son s'interrompt ~1 s le temps de relancer le
    service audio), effet immédiat et 100 % réversible (bouton « Désactiver »
    qui restaure les effets d'origine, « Tout retirer » à la désinstallation).
    La courbe se pilote dans l'onglet Égaliseur (fondu enchaîné 20 ms : le
    son ne s'interrompt jamais, même en plein réglage) ; les mesures de
    calibration contournent automatiquement l'EQ système (on mesure la
    pièce, pas la correction). Limites honnêtes : les flux WASAPI
    exclusif / ASIO contournent tout effet système (pour les DAW, utilisez
    le greffon RoomEq VST dans le DAW lui-même) ; les effets du fabricant (Realtek, Dolby…)
    sont suspendus sur une sortie activée — sauvegardés, restaurés à la
    désactivation ; une mise à jour de pilote peut effacer l'inscription —
    bouton « Réparer » (et réparation automatique au branchement à chaud).
  • NOUVEAU 3.7.0 — FIN DES GELS À CHAQUE CLIC : le rafraîchissement des
    périphériques se fait maintenant en arrière-plan en une seule passe
    (l'interface ne se bloque plus) ; le bouton ⟳ s'anime pendant
    l'actualisation. La latence du routage par câble virtuel est réduite
    (50 → 30 ms) pour limiter le décalage son/image en vidéo — l'EQ système
    (latence nulle) restant la voie recommandée pour « tout le son ».
  • NOUVEAU 3.5.0/3.6.0 — GREFFONS ÉDITABLES DANS LE DAW : le VST 2 32 bits
    Windows (D21) et l'AudioUnit macOS (D19, v3.6.0 en parité) embarquent
    l'égaliseur éditable à la souris (glisser un point = fréquence/gain,
    molette = Q, double-clic = reset, clic droit = type/activation), la
    banque des 321 corrections casques, des VU-mètres et l'auto-chargement
    du dernier preset de l'application. Presets .json RoomEq et .ffp
    Pro-Q 3 chargeables (bouton ou glisser-déposer), état sauvegardé avec
    le projet DAW.
  • EXPORT FABFILTER PRO-Q 3 (.ffp) : onglet Égaliseur, bouton
    « Exporter Pro-Q 3 (.ffp) » — le preset courant (bandes actives +
    préampli, qui devient le gain de sortie du greffon) est écrit en
    fichier binaire chargeable dans FabFilter Pro-Q 3. Limites du greffon
    appliquées : 24 bandes actives maximum, 10 Hz–30 kHz, Q 0,025–40,
    ±30 dB.
  • ANTI-BOUCLE AU ROUTAGE (3.2.0) : un périphérique déjà routé en ENTRÉE
    ne peut pas être choisi comme sortie master (grisé + motif), et
    réciproquement (D18, I-AUD-03 v2).
  • INSTALLATION EN 1 CLIC (3.3.0, D20) : RoomEq-win-Setup.exe (Windows,
    sans droits administrateur) et RoomEq-AU-<version>-macos.pkg (macOS).
  • GREFFON AUDIOUNIT macOS (3.2.0, D19) : « RoomEq Correction » pour
    Ableton Live — livré dans les releases GitHub (zip + pkg).
  • GREFFON VST 2 32 BITS Windows (3.4.0, D21) : pour les DAW 32 bits
    (Live 9, FL 11, Cubase 5, REAPER 32) — copier RoomEq.dll dans le
    dossier VST 32 bits du DAW puis « Rescan » ; auto-chargement du dernier
    preset de l'application à l'ouverture (3.4.1) ; journal
    %LOCALAPPDATA%\RoomEq\logs\roomeq-vst.log.
  • PARITÉ FONCTIONNELLE 2.2.2 ÉTABLIE point par point (docs/PARITE-v2.2.2.md) :
    égaliseur paramétrique, analyseur RTA, calibration multi-signaux, profils
    micro (36), corrections casques (321 modèles AutoEq), preset automatique
    par périphérique, EQ système, lecteur intégré, versions test/public,
    télémétrie de test.
  • CORRECTIFS v3 (documentés) : détection du balayage durcie (une capture de
    bruit seul n'est plus « corrigée »), message d'aide ASIO affiché même sans
    pilote, garde-fou « Lier ce preset » étendu au preset plat, fichier de la
    tranche Lecteur restauré au démarrage, kind « mac » persisté.
  • LES COMPOSANTS NATIFS (pilote de carte virtuelle, DLL ASIO, installateurs)
    sont SCELLÉS en version 2.2.2 et inchangés : mêmes points d'entrée, mêmes
    artefacts — voir natif/REFERENCE-NATIF.md. Le greffon AudioUnit, lui, est

INSTALLATION
------------
    1) APPLICATION WINDOWS EN 1 CLIC : RoomEq-win-Setup.exe — double-clic,
       c'est tout. Installation utilisateur SANS droits administrateur
       (%LOCALAPPDATA%\RoomEq, dossier inscriptible), raccourcis Bureau +
       Menu démarrer, désinstalleur « Paramètres → Applications ».
       Contenu : version publique silencieuse (RoomEq.exe) ; les exécutables
       et le pilote ne sont PAS téléchargés depuis l'application.
       Alternative sans installation : zip portable public/test (voir 3).
       NOTE 3.8.0 : l'application n'installe plus le pilote de carte virtuelle
       (l'EQ système le remplace, sans pilote) ; elle propose seulement de
       SUPPRIMER un éventuel pilote hérité d'une version antérieure.
    2) PILOTE (inchangé, scellé 2.2.2) : RoomEqDriverSetup-2.2.2.exe — la carte
       son virtuelle « RoomEq Virtual Audio » + le pilote ASIO en un fichier.
       Double-clic -> UAC -> fenêtre graphique (état, journal, boutons
       Installer / Diagnostic complet / Revenir au mode normal / Désinstaller).
       Le mode test est PROPOSÉ en boîte de dialogue (jamais activé en silence,
       défaut : NON). Options console : --status / --uninstall / --mode-normal
       / --accept-testmode / --no-testmode.
    3) APPLICATION SANS INSTALLATION (portable) : RoomEq.exe (public,
       silencieux — aucune journalisation, aucun envoi) ou RoomEq-test.exe
       (journalisation complète + télémétrie Drive du développement, pilotée
       par telemetrie.json placé à côté). Au lancement de la version test,
       une boîte de dialogue propose la version publique. ROOMEQ_TEST=1
       force le mode test (développement). Aucun pilote n'est nécessaire :
       l'EQ système fonctionne tel quel.
    4) GREFFON ABLETON (macOS) EN 1 CLIC : RoomEq-AU-<version>-macos.pkg —
       double-clic → RoomEq.component installé dans
       /Library/Audio/Plug-Ins/Components (tous les utilisateurs), attribut
       de quarantaine retiré et base des composants re-scannée
       automatiquement au postinstall. Alternative manuelle : zip
       RoomEq-AU-<version>-macos.zip (natif/roomeq-au/README.md).
    Les réglages et mesures (%APPDATA%\RoomEq : presets, profils micro,
    mixer.json, devicepresets.json, signaux) sont PARTAGÉS avec la 2.2.2 —
    une mesure existante et les presets liés aux sorties sont conservés.
